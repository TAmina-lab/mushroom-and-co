# 🍄 Mushroom & Co.

**A little cap. A big career.**

A whimsical job application form for aspiring forest mushrooms, built with HTML and CSS.

## About the Project

Mushroom & Co. is a fictional job application page where mushrooms can apply for a position in the enchanted forest.

The project combines a playful concept with a vintage woodland-inspired design.

## Live Demo

https://tamina-lab.github.io/mushroom-and-co/

## Built With

- HTML5
- CSS3

## Design

The visual style draws inspiration from vintage botanical illustrations, using earthy colors, forest greens, warm neutrals, and terracotta accents.

## What I Practiced

- Semantic HTML structure
- Forms, labels, and input elements
- CSS selectors and pseudo-classes
- Flexbox and element positioning
- Responsive design with media queries
- Organizing HTML and CSS into separate files
